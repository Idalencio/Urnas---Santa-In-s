# Trabalho neste repositório

O usuário solicitou que o projeto fique estruturado, comentado e que toda alteração
feita por aqui também seja atualizada no GitHub.

- Repositório escolhido: `https://github.com/Idalencio/Urnas---Santa-In-s`.
- A branch principal é `main`. Preserve o histórico e as alterações de outras pessoas.
- Ao concluir uma alteração autorizada, valide, faça commit e envie ao `origin`.
  Confira o commit remoto. Não use force push. Se o envio falhar, informe o bloqueio;
  não afirme que o GitHub está atualizado sem verificá-lo.
- Use mensagens de commit claras e resuma mudanças e validações na entrega.
- Mantenha a estrutura PHP/MySQL, a raiz pública `public`, o histórico da versão
  anterior e o design original do Colégio Santa Inês.
- A configuração pertence à eleição. As urnas são compartilhadas por várias eleições.
- Preserve participação e votos. A exclusão de aluno é lógica, sem remover eleitorados
  publicados. Votos não recebem matrícula ou identificação de eleitor.
- Comente responsabilidades e regras importantes; evite comentários que apenas
  repitam cada linha. Execute o formatador para manter a leitura padronizada.
- `frontend/` é a origem da interface. Depois de alterá-la, execute
  `npm run sync:preview` e as compilações apropriadas.
- A aplicação hospedada está reproduzida em `preview/`. Ao editar o adaptador D1,
  mantenha esse código e o projeto Sites correspondente sincronizados. O projeto
  Sites é `appgprj_6ae1fade410c8191a8dc647c56789b93`; preserve seu público atual.
  Publicar a prévia e atualizar o GitHub são operações distintas.
- O pacote da escola usa PHP/MySQL; a prévia usa D1/R2. Não presuma sincronização
  dos seus dados. Não faça deploy no CloudPanel sem uma solicitação específica.
- Nunca versione `config/config.php`, `config/local-admin.php`, senhas, tokens,
  listas reais de alunos, bancos, logs ou fotos enviadas. Use os arquivos de exemplo.
- Use somente bancos locais descartáveis para os testes. Veja `docs/DESENVOLVIMENTO.md`.
- Não solicite revisões nem envie mensagens a outras pessoas sem instrução do usuário.
